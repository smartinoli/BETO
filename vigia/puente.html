Puente Telegram

Para que el Vigía corra solo cuando tú escribes: sin horarios, sin sesiones esperando, sin nada encendido de fondo. Telegram avisa a un puente, y el puente despierta al Vigía. Se configura una vez y es gratis.

Escribes /barrer → Telegram avisa al puente → El puente despierta al Vigía → Te llega el resultado

1 · Token de GitHub (2 min)

1.1Entra a github.com/settings/personal-access-tokens/new
1.2Nombre: vigia-puente · Expiración: la que quieras (si expira, el bot deja de responder y hay que renovarlo)
1.3En Repository access elige Only select repositories → BETO
1.4En Permissions → Repository permissions, busca Contents y ponlo en Read and write
1.5Genera el token y cópialo (solo se muestra una vez)

Ese token puede escribir en tu repo: no lo pegues en ningún chat, solo en el puente.

2 · Crear el puente en Cloudflare (5 min)

2.1Crea una cuenta gratis en dash.cloudflare.com (no necesitas dominio ni tarjeta)
2.2Menú Workers & Pages → Create → Start with Hello World → nómbralo vigia → Deploy
2.3Entra al Worker → Edit code, borra todo lo que hay y pega el código de abajo → Deploy
2.4Anota la dirección que te queda, del tipo https://vigia.TUCUENTA.workers.dev

3 · Las cinco variables del puente (3 min)

En el Worker: Settings → Variables and Secrets → Add. Crea estas cinco (marca Secret en las tres primeras):

NombreValor
TG_TOKENel token de tu bot (el mismo del secreto de GitHub)
GH_TOKENel token del paso 1
TG_SECRETuna palabra larga que inventes, sin espacios (ej. beto-puente-2026-xyz). Sirve para que nadie más pueda fingir ser Telegram
TG_CHATtu chat id (el mismo del secreto de GitHub)
GH_REPOsmartinoli/BETO

Guarda y vuelve a Deploy para que tome las variables.

4 · Conectar Telegram al puente (1 min)

Abre esta dirección en tu navegador, reemplazando las tres partes en mayúsculas por lo tuyo:

https://api.telegram.org/botTU_TOKEN_DE_BOT/setWebhook?url=https://vigia.TUCUENTA.workers.dev&secret_token=TU_TG_SECRET

Si responde {"ok":true,...}, quedó conectado. Manda /estado al bot: debería contestarte "⏳ Recibido" en el acto y el resultado en menos de un minuto.

Para desconectarlo algún día: https://api.telegram.org/botTU_TOKEN/deleteWebhook
